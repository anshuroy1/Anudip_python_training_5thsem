# Smart Task Management System

A Python-based task management system developed as a college project.

## Current Features
- Add Task
- Task ID validation
- Duplicate Task ID validation
- Task title validation
- Task description validation
- Priority validation
- Due date validation
- Past date validation

## Technologies Used

- Python
- Object-Oriented Programming
- datetime module

## Project Status

🚧 Currently under development.

More features such as View Task, Update Task, Delete Task, Task Completion, Smart Recommendations, and Dashboard will be added.
